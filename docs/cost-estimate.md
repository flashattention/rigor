## 1. 합성 케이스 1건의 토큰 (가정)
가정: 합성 저장소 3개(작음), 공고 요건 약 15개.

| 단계 | 입력 | 출력 |
|---|---|---|
| 작은 작업 (공고 파싱, 저장소 요약·대조, 검증) | 80k | 8k |
| 판단 작업 (요건 판정, 진단문, 로드맵) | 30k | 8k |
| 합계 | 110k | 16k |

Claude 4.7 이후 모델은 같은 텍스트에 토큰이 약 30% 더 나온다(공식 문서). 그래서 Claude 계산에는 ×1.3을 적용한다(입력 143k, 출력 21k).

| 모델 | 케이스 1건 | Batch API (50% 할인) |
|---|---|---|
| Claude Haiku 5.5 ($0.10 / $0.50) | 약 ₩35 | 약 ₩17 |
| GPT-5 nano ($0.05 / $0.40, 미검증) | 약 ₩17 | 약 ₩9 |
| GPT-5 mini ($0.25 / $2, 미검증) | 약 ₩83 | 약 ₩42 |

| 평가 | 실행 수 (케이스 환산) |

## 3. M1 전체 예상 (Haiku 5.5 단계)
| 안 | 내용 | 예상 |
|---|---|---|
| A. 절약형 | 항상 Batch, 스모크 10회, 전체 평가 1회(M1 끝) | 약 ₩6,500 |
| **B. 표준형 (권장)** | 항상 Batch, 스모크 15회, 전체 평가 2회(중간·끝) | 약 ₩11,000 |
| C. 빠른 반복형 | Batch 없이(결과를 바로 받음), 스모크 15회, 전체 평가 2회 | 약 ₩22,500 |

Batch API는 결과가 늦게 온다(최대 24시간). 그 대신 비용이 절반이다. 개발 속도와 비용을 맞바꾸는 선택이다.

**OpenAI 단계(남은 약 $4 ≈ ₩5,600)**: 파이프라인이 끝까지 도는지 확인하는 용도다. nano 기준 약 300건분이라 충분하다. 크레딧이 떨어지면 Haiku 단계 전까지 Fake LLM으로 개발한다. 추가 충전은 하지 않는다.

## 4. 지출이 예산을 넘지 않게 하는 장치
- 실제 호출 평가 명령은 실행 전에 예상 비용을 출력하고 확인을 받는다(`--yes` 없이는 실행 안 함).
- 평가 실행마다 실제 토큰·비용을 `evals/reports/`에 기록하고, 월 누적이 상한의 80%가 되면 경고한다.
- Max에 포함된 API 크레딧 금액, 그리고 크레딧 소진 후 카드로 과금되는지는 결제 후 콘솔에서 확인한다. 콘솔에서 월 지출 한도를 설정할 수 있으면 설정한다.
