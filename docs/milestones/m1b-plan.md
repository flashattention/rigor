# M1b 계획 (개정: 2026-11-01)

> M1a 종료 후 "포트폴리오·제품 가치" 점검(면접관 시점)을 반영해 우선순위를 바꿨다.
> 원칙: 기능을 더 붙이기 전에 **본인 소유 증명**과 **외부 근거가 있는 숫자**를 먼저 확보한다.

## 왜 바꿨나
| 면접관이 찌를 약점 | 이번 계획의 대응 |
|---|---|
| "본인이 만들었나?" — 대부분 AI 공동 작성 | 소유 트랙: 핵심 모듈 4개 직접 리뷰 + 연습 과제 |
| "Agent라면서 에이전트가 어디 있나?" | 근거 탐색 에이전트를 규칙·검색과 비교하는 실험 (M2 → M1b로 당김) |
| "평가 점수가 무슨 의미인가?" — 자기 설계 합성 데이터 | 본인 실데이터로 써 보기 + 지인 3~5명 + 공개 저장소 |
| "쓰는 사람이 있나?" | 위와 같음, 항목별 "맞는 말/틀림" 집계 |

## 순서
| 단계 | 내용 | 산출물 | 비용 |
|---|---|---|---|
| **1. 본인 데이터로 써 보기** | 본인 이력서 + GitHub(공개 API)로 `rigor diagnose` 실행. 틀린 지적을 하나씩 확인한다. 각 오류는 실패 분류 체계에 기록하고, **합성 데이터로 재현한 회귀 테스트**로 옮긴다 (실데이터는 저장소에 넣지 않음) | `docs/failure-taxonomy.md`, 회귀 테스트, 수정 커밋 | 실행당 약 $0.005 (OpenAI 잔여 크레딧) |
| **2. 평가 러너 + Haiku 기준선** | 정확도, 판정 안정성(5회), 아첨 저항(압박 턴 후 등급 불변), 인젝션 방어, 반사실 공정성. 실행 전 비용 확인, 녹화 응답은 CI 재생용으로 커밋 | `rigor eval`, `evals/reports/` 첫 기준선 | B안 약 ₩11,000 (Max 크레딧) |
| **3. 에이전트 비교 실험** | 규칙이 보류한 claim의 근거 찾기: ① 규칙 ② +BM25 ③ +LLM 대조 ④ 읽기 전용 도구 에이전트. 근거 위치 정답이 있는 합성 저장소 + 공개 저장소 몇 개로 recall@k·비용·지연 비교 | LLM 클라이언트의 tool calling 지원, 실험 보고서, ADR-0010 개정 | 수백 원 수준 |
| **4. 지인 3~5명** | CLI를 같이 돌리고 항목별 "맞는 말 / 틀림 / 이미 해결됨"을 받는다. 결과물·이력서는 각자 보관하고, 저장소에는 **익명 집계만** 남긴다 | `docs/research/m1b-pilot.md` (집계·인용 없는 요약) | 실행당 약 $0.005~0.01 |
| **5. README를 2분짜리 이야기로** | 무엇을 풀었나 → 어떻게 검증했나 → 어디서 깨졌나 → 숫자. ADR은 링크로만 | README 개편 | 0 |

## 소유 트랙 (1~5와 병행)
코드를 면접에서 설명할 수 있게 만드는 작업이다. 대상 모듈은 넷이다.
- `core/grading.py` (등급 규칙)
- `github_audit/claims.py` (claim 검증)
- `nodes/reconcile.py` (정합)
- `synth/` + 평가 러너 (평가 설계)

| 방식 | 내용 |
|---|---|
| 코드 읽기 | 모듈마다 10~15분. 이해가 안 되는 줄은 질문으로 남긴다 |
| 연습 과제 | `docs/interview-notes.md`의 과제 중 모듈당 1개 이상 **직접** 구현 (AI 도움 없이, 또는 도움 범위를 커밋 메시지에 정직하게 표시) |
| 확인 | 면접 노트의 예상 질문에 답을 직접 써 넣는다 |

## 뒤로 미룬 것
HWP/HWPX·OCR 입력, MCP, 매칭, 웹 배포 → M2 이후. 1~5에서 나온 실패가 이것들보다 우선이다.

## 완료 기준
- 본인 데이터 실행에서 나온 오류가 모두 분류·재현 테스트·수정(또는 "알려진 한계"로 명시)됐다.
- Haiku 기준선 보고서에 판정 안정성·아첨 저항·인젝션 방어·반사실 공정성 수치가 표본 수와 함께 있다.
- 에이전트 실험이 "채택/기각"을 수치로 결론 냈다.
- 외부 피드백(본인 + 지인)의 "맞는 말" 비율이 집계됐다.
- README만 읽어도 문제·검증·한계·숫자가 2분 안에 전달된다.
