# 실패 분류 체계

> 실제 실행에서 나온 실패를 유형별로 기록한다. 흐름: 실패 → 분류 → 합성 재현 테스트 → 수정 → 재평가. 실데이터는 저장소에 넣지 않는다. 재현 테스트는 `tests/test_dogfood_regressions.py`.

| 유형 | 정의 | 사용자에게 미치는 해 |
|---|---|---|
| F1 입력 손실 | 파싱·정규화에서 정보가 사라짐 | 있는 근거를 없다고 지적 |
| F2 개인정보 누출 | 보호 속성·식별어가 LLM에 전달됨 | 공정성·개인정보 원칙 위반 |
| F3 귀속 오류 | 커밋을 본인 것으로 세지 못함 | 기여를 실제보다 작게 표시 |
| F4 오탐 지적 | 사실인 내용을 문제라고 지적 | 신뢰 상실, 부당한 이력서 수정 유도 |
| F5 강건성 | 항목 하나의 문제가 전체 실행을 멈춤 | 결과를 받지 못함 |
| F6 쓸 수 없는 출력 | 맞더라도 분량·구성 때문에 행동으로 옮길 수 없음 | 리포트를 읽지 않음 |
| F7 변별력 부족 | 판정이 근거의 강도를 구분하지 못함 | 과도한 낙관 |
