# ADR-0002: 에이전트 프레임워크와 그래프 구조

- 상태: 채택됨 (2026-11-01)
- 날짜: 2026-11-01
- 관련: ADR-0001, `docs/design.md` §2.2

## 배경
요구사항: ① 여러 단계의 고정 흐름 + 조건 분기(검증 실패 시 해당 노드만 재실행) ② **사람 확인(interrupt) 후 재개**, 서버 재시작 후에도 재개 ③ 병렬 실행(저장소 감사와 요건 판정) ④ 노드 단위 trace ⑤ Fake LLM으로 테스트. 이 흐름은 "자율 에이전트"보다 **결정된 워크플로 + 일부 LLM 판단**에 가깝다.

## 검토한 선택지

| 기준 | LangGraph | 순수 Python + LLM SDK | Pydantic AI (+graph) | 벤더 Agent SDK (Claude Agent SDK, OpenAI Agents SDK 등) |
|---|---|---|---|---|
| 고정 흐름·조건 분기 | StateGraph로 명시적 | 직접 작성(가장 단순) | 지원 | 자율 루프 중심, 고정 흐름은 부자연스러움 |
| interrupt·재개 | 내장, Postgres checkpointer 공식 제공 | 상태 저장·재개 직접 구현 | 일부 지원, 영속 재개는 직접 | 제한적 |
| 병렬 실행 | Send/병렬 노드 | asyncio.gather | 지원 | 제한적 |
| 모델 제공자 종속 | 없음 | 없음 | 없음 | 해당 벤더 중심 |
| 추상화 비용 | 중간(학습 곡선, 버전 변화 잦음) | 없음 | 낮음~중간 | 낮음 |
| 채용 시장 신호 | Agent Engineer 공고에서 자주 요구 | 기본기 증명 | 신흥 | 벤더별 |
| 디버깅·시각화 | 그래프 시각화, LangSmith 연동 | 직접 | Logfire 연동 | 벤더 콘솔 |

## 결정
**LangGraph**를 배선·상태·재개·병렬 계층으로 쓰고, **노드 로직은 프레임워크와 무관한 순수 함수**(`app/rigor/core`, `nodes`)로 작성한다.

그래프 구조: **상위 오케스트레이터 + 서브그래프 4개**(진단 / GitHub 감사 / 로드맵 / 검증). 매칭 서브그래프는 M4 이후 추가.

## 이유
1. interrupt 후 영속 재개를 직접 구현하면 checkpointer·직렬화·버전 호환까지 만들어야 한다. 이 서비스의 HITL(프로필 확인)과 서버 배포 요구에 정확히 맞는 기능이 LangGraph에 있다.
2. 순수 함수 분리로 **잠금 효과를 줄인다**: LangGraph를 걷어내도 core·nodes는 그대로 쓸 수 있다. 면접에서 "프레임워크가 무엇을 해 주고 무엇을 안 해 주는지" 설명할 근거가 된다.
3. 서브그래프 분리로 각 기능을 독립적으로 평가·테스트할 수 있다(감사 서브그래프만 평가셋으로 돌리기 등).

## 결과·트레이드오프 (포기한 것)
- LangGraph 버전 변화에 따른 유지보수 비용 → 버전 고정, 업그레이드는 평가 게이트 통과 시에만.
- 순수 Python 대비 추상화 학습 비용 → 그래프 배선 코드는 최소화.
- 벤더 Agent SDK의 자율 도구 사용 능력은 쓰지 않는다. 이 제품은 자율성보다 **예측 가능성과 근거 추적**이 중요하기 때문이다.

## 재검토 조건
- interrupt·checkpointer를 실제로 쓰지 않게 되면(예: 웹 UI에서 확인을 그래프 밖 단계로 처리) → 순수 Python으로 단순화 검토.

## 승인 기록 (2026-11-01)
- 승인: `flashattention`. 프레임워크 기능(영속 재개)과 잠금 회피(순수 함수 core)의 균형을 이유로 채택.
- **비용 관점**: LangGraph 라이브러리(오픈소스)만 사용하고, 유료 호스팅 실행 플랫폼은 쓰지 않는다 — 그래프는 우리 워커에서 실행한다. 비용은 전부 LLM 호출에서 나오므로, 결정론 우선 원칙(`design.md` §3)이 곧 비용 절감책이다.
