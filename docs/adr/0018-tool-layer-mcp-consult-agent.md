# ADR-0018: 도구 계층(MCP)·진단 상담 에이전트·Postgres 앞당김

- 상태: 채택됨 (2026-11-01)
- 날짜: 2026-11-01
- 관련: ADR-0001, 0002, 0004, 0008, 0010(개정), 0017(개정), `docs/milestones/m1b-plan.md`

## 배경
M1a 이후 점검에서 두 가지가 드러났다.
1. 지금 구조는 잘 만든 워크플로이지만, LLM이 도구를 골라 쓰는 곳이 없다. Agent Engineer 포트폴리오로는 "에이전트가 필요한 곳을 골라 다른 방식과 비교해 수치로 보였다"가 필요하다.
2. 사용자는 MCP, Vector DB, Tool calling, FastAPI, PostgreSQL을 보여 주고 싶어 한다.

단, 기술 이름을 붙이려고 넣는 것은 RIGOR가 이력서에서 잡아내는 "키워드 나열"과 같다. **원칙: 각 기술은 진짜 문제를 하나씩 맡고, 대안과 비교한 숫자로 정당화한다.**

## 결정

| 기술 | 맡는 문제 | 정당화 방식 |
|---|---|---|
| Tool calling ① 근거 탐색 에이전트 | 규칙이 보류한 claim의 근거를 저장소에서 찾는다. 어느 파일을 열지 미리 알 수 없다 | 규칙 / BM25 / 벡터 / 에이전트의 recall@k·비용·지연 비교 실험 → 채택 여부 결정 |
| Tool calling ② 진단 상담 에이전트 | 리포트 이후의 질문("왜 미충족?", "X를 하면 등급이 오르나?")에 답한다. 도구: 리포트 조회, 근거 검색, **등급 시뮬레이터**(ADR-0008 규칙). 등급은 도구가 계산하므로 말로 설득해도 바뀌지 않는다 | 압박 대화에서의 등급 불변율, 도구 호출 정확도, 인용 정확도 |
| MCP | 위 도구들을 **MCP 서버 하나**로 만든다. 내부 에이전트와 사용자의 MCP 클라이언트(Claude Desktop/Code 등)가 같은 도구 계층을 쓴다. 처음에는 **로컬 stdio 전송만** 연다 | 원격 노출·인증·비용 위험 없음. 도구는 읽기 전용, 본인 데이터만 |
| Vector DB (pgvector) | 큰 저장소의 근거 검색 (실험 비교군). 이기면 채택. 나중에 공고 매칭(ADR-0016) | ADR-0010 실험 결과 |
| FastAPI + PostgreSQL | 실행 결과·감사 캐시(커밋 해시 기준)·작업 큐 저장, SSE 진행 표시. LangGraph interrupt를 Postgres checkpointer에 저장해 재시작 후 재개 | 캐시 적중, 재시작 후 재개 시연 |

**순서 (M1b)**: 본인 데이터 실행 → FastAPI+Postgres 골격과 LangGraph 연결 → 근거 탐색 에이전트 + 벡터 비교 실험 → MCP 서버(로컬) → 진단 상담 에이전트 → 평가 러너·Haiku 기준선(12월)·README.

**개발 환경**: 로컬 Postgres는 Docker Desktop(사용자 설치)의 `pgvector/pgvector` 이미지. CI는 GitHub Actions 서비스 컨테이너. 비용 0원.

## 이유
- 각 기술이 실제 문제를 맡고 숫자로 정당화되므로, 면접에서 "썼다"가 아니라 "골랐다"를 보여 줄 수 있다.
- 진단 상담 에이전트는 tool calling의 강점(대화형 질의)과 RIGOR의 원칙(등급은 규칙, 아첨 금지)을 동시에 보여 준다. LLM이 도구 결과를 무시하고 등급을 바꾸려 해도 등급의 출처는 도구다.
- MCP 서버를 내부 에이전트와 외부 클라이언트가 공유하면 도구 정의가 한 곳에 모인다.

## 결과·트레이드오프 (포기한 것)
- M1b 범위가 커진다. HWP/OCR 입력, 매칭, 웹 배포는 M2 이후로 밀린다.
- 진단 상담 에이전트는 다중 턴 호출이라 진단 1건보다 비용이 클 수 있다. 턴 수·도구 호출 수 상한과 비용 계측을 둔다.
- 벡터 검색은 실험에서 지면 채택하지 않는다. "넣었다가 숫자를 보고 뺐다"도 결과로 남긴다.

## 재검토 조건
- 근거 탐색 실험에서 에이전트·벡터 모두 BM25 대비 의미 있는 개선이 없을 때 → 해당 기능을 채택하지 않고 실험 보고서만 남긴다.
- MCP를 원격(HTTP)으로 열 필요가 생길 때 → 인증·권한·비용 상한을 다룬 새 ADR.
