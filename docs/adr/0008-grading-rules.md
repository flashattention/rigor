# ADR-0008: 등급 산출 규칙 (결정론 + 근거 있는 기준값)

- 상태: 채택됨 (2026-11-01)
- 날짜: 2026-11-01
- 관련: `docs/rubric.md` §2, ADR-0009, `docs/metrics.md` §0

## 배경
RIGOR의 핵심 출력은 공고 적합도 등급(강력 추천 / 지원 가능 / 갭 보완 후 / 비추천)이다. 두 가지를 정해야 했다.
1. 등급을 누가 정하나: LLM이 직접 정하나, 규칙이 계산하나.
2. 규칙의 기준값을 무엇으로 정하나.

처음 초안(0.4 / 0.7 / 0.9, 연차 50% 미만이면 결격)은 근거 없이 정한 숫자였다. 사용자가 "감으로 정하지 말고 근거를 가지고 정하라"고 지적해 다시 썼다.

## 검토한 선택지

| 기준 | A. LLM이 등급을 직접 출력 | B. 가중합 점수 + 임의 기준값 | **C. 요건별 판정 → 규칙 계산, 기준값마다 근거 명시** |
|---|---|---|---|
| 같은 입력 → 같은 등급 | 보장 안 됨 | 판정이 같으면 보장 | 판정이 같으면 보장 |
| 아첨 방어를 테스트로 증명 | 어려움 | 가능 | 가능 |
| 사용자에게 "무엇이 바뀌면 오르나" 설명 | 어려움 | 가능 | 가능 + 기준의 출처까지 |
| 기준값의 정당성 | — | 없음 | 정의·외부 자료·오류 비용에서 나옴 |
| 비용 | LLM 호출 필요 | 0 | 0 |

## 결정
C. 규칙과 근거는 `docs/rubric.md` §2에 있다. 요약하면 다음과 같다.
- **정의 기반 (숫자 없음)**: knockout 미충족이면 비추천이다. knockout은 학위·자격증·근무 자격·근무지로 한정한다. 강력 추천은 "필수 요건에 빈칸 없음 + 핵심 요건 근거 완전 + 이를 보여 줄 저장소 있음"이다.
- **외부 근거 (잠정값)**: 필수 요건 충족률 40% 미만은 비추천, 40~60%는 갭 보완 후, 60% 이상은 지원 가능이다. 근거는 TalentWorks 분석(지원서 6,000건 이상)이다. 40~50% 충족부터 면접률이 뚜렷이 오르고, 60%를 넘으면 더 오르지 않았다. 핵심 역량 미충족이 1개라도 있으면 갭 보완 후다(같은 자료의 "핵심 하드 스킬은 만회 어려움" 단서).
- **오류 비용 비대칭**: 연차 미달은 knockout이 아니다. 판단할 근거가 모자란 `unknown`은 결격으로 처리하지 않고 질문으로 돌린다.
- **관례값 (근거 없음을 명시)**: `partial`=0.5, 연차 50% 경계, 최근성 2년. 민감도 분석 대상이다.

## 이유 (사용자 승인 사유 포함)
1. 등급이 판정의 함수이면 같은 근거에서는 같은 등급이 나온다. 그러면 아첨 테스트와 판정 안정성 지표가 성립한다.
2. RIGOR의 제품 원칙은 "근거 없는 말은 하지 않는다"이다. 등급 기준값에도 같은 원칙을 적용해야 일관된다.
3. 잘못된 비추천이 잘못된 지원 권유보다 사용자에게 더 큰 손해다(기회 상실 > 몇 시간의 지원서 작성). 애매하면 덜 배제한다.

## 결과·트레이드오프 (포기한 것)
- 외부 근거가 약하다. TalentWorks 분석은 동료 평가를 거친 연구가 아니고, 미국 전 직군 데이터이며, 2018년 자료다. 요건 충족률을 세는 방식도 RIGOR와 다르다. 이 한계를 README와 서비스 화면에 공개한다.
- 규칙이 단순해서 공고마다 다른 실제 기준(회사 내부 사정)은 반영하지 못한다. 이는 브리프 §5.2의 한계 고지("회사 내부 기준은 알 수 없음")와 같은 내용이다.

## 재검토 조건
- 베타 결과 데이터로 등급별 서류 합격률을 측정할 수 있게 되면(`metrics.md` §2.3) 기준값을 다시 보정한다.
- 요건 충족률과 면접률의 관계를 다룬 동료 평가 연구를 찾으면 근거를 교체한다.
